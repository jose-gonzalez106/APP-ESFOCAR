# ESFOCAR App 📚

App Android para estudiantes y docentes de la **Escuela de Formación de Carabineros (ESFOCAR)**.
Permite guardar material de estudio en el celular y revisarlo **sin internet**.

> 🚧 MVP (versión inicial) · Proyecto académico

## ¿Qué puedes hacer?

**Estudiantes**
- Crear una cuenta y elegir tus asignaturas
- Subir tus documentos (PDF, imágenes o texto)
- Abrirlos y estudiar sin conexión
- Ver tus documentos más recientes en el inicio

**Docentes**
- Crear una cuenta (el usuario empieza con `Docente_`)
- Subir material para las asignaturas que imparten

**Todos**
- Cambiar la foto de perfil
- La sesión queda iniciada al volver a abrir la app
